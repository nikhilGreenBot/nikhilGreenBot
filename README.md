# Hi, I'm Nikhil Bastikar 👋

I'm an **App Developer and Tech Enthusiast** passionate about building beautiful, production-quality native and cross-platform mobile applications — from SwiftUI on iOS to Jetpack Compose on Android.

## 🚀 My Projects

### ✨ [FitzNi Pins — Android](https://github.com/nikhilGreenBot/fitzni-pins-android)

A production-quality Android app for Disney trading pin collectors. Named after my wife Katie Fitzsimmons + Nikhil — built with the full modern Android stack.

- 🏗️ **Clean Architecture** — Domain / Data / Presentation / UI layers with strict separation
- 🎨 **Jetpack Compose + Material 3** — Disney-inspired theme, dynamic color, animated splash
- 💉 **Hilt DI** — `@HiltViewModel`, scoped modules, zero manual wiring
- 🗄️ **Room + DataStore** — Local-first with upserts, FTS search, and preference storage
- 🔄 **UDF State Management** — `StateFlow<UiState>` + `Channel<UiEffect>`, sealed `FitzNiResult<T>`
- 🔍 **Pin Identification** — Camera capture → confidence-scored AI match candidates
- ✅ **JUnit5 + Turbine + MockK** — ViewModel Flow tests, sealed error path coverage

### 🎢 [TinkerTime](https://github.com/nikhilGreenBot/TwinkleTogether)

A magical couples app for planning theme park adventures together. Built natively with SwiftUI for iOS.

- ✨ **Trip Countdown** — Sparkle animations counting down to your next adventure
- 💕 **Partner Sync** — Share trips and compete on daily steps via iCloud/CloudKit
- 🏃 **Health Tracking** — Apple HealthKit integration for step goals
- 🎨 **Beautiful Themes** — Multiple customizable color themes
- 📱 **Home Screen Widgets** — Beautiful countdown & step tracking widgets

### ⚡ [Skimpulse](https://nikhilgreenbot.github.io/skimpulse/)

A beautifully crafted technology articles aggregator app built with Flutter. Stay updated with the latest tech stuff.

- 📱 Available on iOS & Android
- ⚡ Built with Flutter & Dart
- 🎨 Clean, modern UI with dark/light themes
